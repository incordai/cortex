# Basic Workflow: From Training to Inference

This example corresponds to the [book's guide](https://cortex.dev/books/cortex/basic-workflow/).

## Example Usage


### Training

```sh
cargo run -p guide --bin train --release
```

### Inference

```sh
cargo run -p guide --bin infer --release
```

### Print the model

```sh
cargo run -p guide --bin print --release
```
